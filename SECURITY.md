# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `enterprise-agent-monorepo`, please do NOT open a public issue.

Instead, please report security issues privately by emailing `security@entropyparadox.com` or creating a private security advisory on GitHub.

We will acknowledge receipt within 48 hours and provide a timeline for a patch.
